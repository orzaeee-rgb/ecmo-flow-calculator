# ECMO Flow Calculator

ECMO Flow Calculator based on Body Surface Area (Mosteller Formula).

## Features

- BSA Calculator
- ECMO Flow (CI 2.4 / 2.6 / 2.8)
- Print Report
- Offline PWA
